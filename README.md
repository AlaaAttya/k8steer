# k8steer

A native macOS desktop application for managing Kubernetes clusters — built with Swift and
SwiftUI, powered by a pure Swift Kubernetes client.

k8steer is for Mac engineers who want a lightweight, private, keyboard-first cluster
workspace that feels like a first-party Apple app: command palette, multi-window support,
Keychain-backed credentials, and no Electron runtime. All data stays on your machine; the
app talks only to your Kubernetes API servers.

**Stack**: Swift 6+, SwiftUI + AppKit, [Swiftkube/client](https://github.com/swiftkube/client)

**Status**: Early development — see [constitution](.specify/memory/constitution.md) for
project principles and scope.
